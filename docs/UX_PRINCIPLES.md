# Principios UX

## Claridad antes que densidad

La vista inicial no debe abrir con texto legal extenso. Debe responder primero:

- Que es esta norma.
- Si esta vigente.
- A quien afecta.
- Que obliga.
- Que prohibe.
- Que derechos reconoce.
- Que sanciones preve.
- Que cambio recientemente.
- Que fuentes respaldan la informacion.

## Trazabilidad visible

Cada explicacion debe poder expandirse hacia:

- Texto legal original.
- Cita.
- Fuente.
- Confianza.
- Estado de revision.

## No asesoramiento personalizado

Evitar frases como:

```text
En tu caso estas obligado a hacer X.
```

Preferir:

```text
Esta norma alcanza, en general, a sujetos con estas caracteristicas. Para determinar si aplica a un caso concreto puede requerirse revision profesional.
```

## Incertidumbre honesta

La UI debe mostrar cuando:

- Un dato esta desactualizado.
- Hay cambios pendientes de validacion.
- Una relacion tiene baja confianza.
- Una explicacion fue extraida automaticamente.
