# Estados visibles

## Estado legal

La UI debe mostrar de forma clara:

- Vigente.
- Derogado.
- Modificado.
- Parcialmente vigente.
- Suspendido.
- Propuesto.
- Historico.
- Desconocido.

## Estado de revision

La UI debe distinguir:

- Extraido automaticamente.
- Necesita revision.
- Revisado.
- Rechazado.

## Confianza

La confianza no debe ocultarse cuando el dato es interpretado.

Estados:

- Alta.
- Media.
- Baja.

## Freshness

Estados:

- Actualizado.
- Parcial.
- Desactualizado.
- Desconocido.
